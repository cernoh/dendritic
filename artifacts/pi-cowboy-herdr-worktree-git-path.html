Incident report / pi-cowboy / 2026-10-15

pi-cowboy is not broken.
herdr's worktree runtime
cannot reach git.

Two cowboy_agent spawns died with could not create the herdr worktree: No such file or directory (os error 2). The orchestrator code is correct. Every herdr command that touches a git worktree fails, because the herdr server is started by herdr-web.service — a unit whose explicit PATH lists five store directories and not one of them contains git. pi-cowboy asks herdr to create a worktree; herdr runs Command::new("git"); the spawn fails; the agent never starts.

Prompt that produced thistest pi cowboy and see if its not working.
VERDICT

pi-cowboy is working code hitting a broken environment. Disable nothing, patch nothing upstream — add git to the herdr-web unit's PATH in this repo (1 line + 2 doc lines), rebuild, restart the service. Reproduced and fixed in an isolated probe: identical PATH without git → the exact production error; same PATH with git → success.

fn repository_git_command(repo_root: &Path, trust_repository: bool) -> std::process::Command {
    let mut command = crate::noninteractive_process::command("git");
    command.args(repository_git_args(repo_root, trust_repository));
    command
}

// src/worktree.rs:494 — what `herdr worktree list` actually runs, and
// where "No such file or directory (os error 2)" comes from: a failed spawn

        .output()
