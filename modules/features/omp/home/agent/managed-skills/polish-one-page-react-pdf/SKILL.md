Use @react-pdf/renderer with A4, compact typography, a strong single-color header rule, and a two-column layout for experience/education plus skills/additional details. Preserve all source content and dynamic date calculations. Regenerate with npm run build:cv, then run npm run lint and npm run build. If pdfinfo is unavailable, inspect the PDF bytes and verify one page object.
