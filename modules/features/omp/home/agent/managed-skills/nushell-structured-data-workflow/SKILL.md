description: "Use when applying a repeatable Nushell workflow to inspect, aggregate, clean, and export structured data."
---

Use the existing `nushell-comb-structured-data` managed skill. Start with `open` and `describe`, inspect nested layers with `get`/`select`, narrow early with `where`/`reject`, aggregate with `group-by`/`items`/`math`, clean nulls with `compact`, and export with `to json`/`to csv`/`save`. Refer to the dedicated load, navigate, and transform skills instead of duplicating their command reference.
